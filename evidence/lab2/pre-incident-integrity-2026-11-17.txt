2. Physical stock reconciliation
Every product's on-hand quantity should match the sum of its stock movements.

SELECT p.sku,
       i.on_hand_qty,
       NVL(SUM(sm.quantity_delta), 0) AS ledger_qty
FROM dgdb.products p
JOIN dgdb.inventory i ON i.product_id = p.product_id
LEFT JOIN dgdb.stock_movements sm
       ON sm.product_id = p.product_id
GROUP BY p.sku, i.on_hand_qty
HAVING i.on_hand_qty <> NVL(SUM(sm.quantity_delta), 0)
ORDER BY p.sku;  

no rows selected

Expected: no rows selected.

Any returned row represents an inventory discrepancy.

3. Reserved stock reconciliation
Reserved inventory must agree with active checkout and allocated reservations.

SELECT p.sku,
       i.reserved_qty,
       NVL(SUM(CASE
           WHEN r.status IN ('CHECKOUT', 'ALLOCATED')
           THEN r.quantity ELSE 0
       END), 0) AS allocation_qty
FROM dgdb.products p
JOIN dgdb.inventory i ON i.product_id = p.product_id
LEFT JOIN dgdb.reservations r
       ON r.product_id = p.product_id
GROUP BY p.sku, i.reserved_qty
HAVING i.reserved_qty <> NVL(SUM(CASE
           WHEN r.status IN ('CHECKOUT', 'ALLOCATED')
           THEN r.quantity ELSE 0
       END), 0)
ORDER BY p.sku;

no rows selected.

Expected: no rows selected.

This checks stored reservations, not whether a checkout deadline has passed.
