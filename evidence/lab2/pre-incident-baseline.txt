Pre-incident stock reconciliation — user-supplied SQL*Plus results
-----------------------------------------------------------------
Physical inventory versus stock-movement ledger:
SELECT p.sku,
       i.on_hand_qty,
       NVL(SUM(sm.quantity_delta), 0) AS ledger_qty
FROM products p
JOIN inventory i ON i.product_id = p.product_id
LEFT JOIN stock_movements sm ON sm.product_id = p.product_id
GROUP BY p.sku, i.on_hand_qty
HAVING i.on_hand_qty <> NVL(SUM(sm.quantity_delta), 0)
ORDER BY p.sku;
Result: no rows selected.

Reserved inventory versus active CHECKOUT and ALLOCATED reservations:
SELECT p.sku,
       i.reserved_qty,
       NVL(SUM(CASE
                 WHEN r.status IN ('CHECKOUT', 'ALLOCATED')
                 THEN r.quantity
                 ELSE 0
               END), 0) AS allocation_qty
FROM products p
JOIN inventory i ON i.product_id = p.product_id
LEFT JOIN reservations r ON r.product_id = p.product_id
GROUP BY p.sku, i.reserved_qty
HAVING i.reserved_qty <> NVL(SUM(CASE
                                  WHEN r.status IN ('CHECKOUT', 'ALLOCATED')
                                  THEN r.quantity
                                  ELSE 0
                                END), 0)
ORDER BY p.sku;
Result: no rows selected.
